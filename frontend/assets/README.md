# TradeLab Icon

Place your custom `icon.ico` file in this directory to use it for the desktop shortcut.

## Icon Requirements

- **Format**: `.ico` (Windows Icon format)
- **Recommended Sizes**: 16x16, 32x32, 48x48, 256x256 pixels (multi-resolution ICO file)
- **Location**: `frontend/assets/icon.ico`

## Creating an Icon

You can create an icon file using:
- Online tools: https://convertio.co/png-ico/ or https://www.icoconverter.com/
- Image editors: GIMP, Photoshop, or online editors
- Icon generators: https://www.favicon-generator.org/

## Design Tips

- Use a simple, recognizable design
- Ensure it looks good at small sizes (16x16)
- Consider the green theme of TradeLab
- Use high contrast for visibility

If no `icon.ico` file is found, the shortcut will use the default Windows icon.
